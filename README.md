# The Legacy — Image Generation

The Legacy is a governed visual-source validation and production system. It converts approved visual masters into repeatable generated assets while preventing source contamination, measuring reconstruction drift, and separating experimental evidence from production output.

## Authority map

- **Google Drive:** authority for canonical visual masters, raw generations, evaluation evidence, approved production outputs, and released handoff packets.
- **This public GitHub repository:** authority for versioned text controls—project instructions, source-manifest metadata, prompts, rubrics, experiment definitions, dashboard source text, handoffs, and change history. It intentionally contains no canonical art or raw visual evidence.
- **ChatGPT projects:** active workspaces only. They do not become the durable or canonical source of record.

## Constitutional rule

> A source controls only its assigned component.

Generated descendants are evidence or production outputs. They never become identity authorities unless Nate explicitly promotes one.
