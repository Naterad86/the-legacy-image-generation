# The Legacy — Durable Visual Grammar

**Status:** ACTIVE  
**Version:** 0.1  
**Decision date:** 2026-08-21

## Purpose

Define the visual qualities that should survive across Legacy productions without forcing every medium to imitate one reference image.

The constitutional rule remains:

> A source controls only its assigned component.

This grammar governs permitted aesthetic treatment. It does not replace the canonical masters, enlarge their identity jurisdictions, or make a generated descendant authoritative.

## Production rendering default

Production-facing Legacy environments are deliberately rendered by default. A photograph may supply subject matter, composition, camera, architecture, spatial relationships, or validation evidence, but it does not silently require a photographic-looking successor.

Literal photographic preservation is a special validation profile and must be explicitly authorized before generation. Input file type never selects the output modality by itself.

## Durable cross-modal invariants

Every Legacy production should express these qualities in the native language of its selected modality:

- premium, intentional, high-craft finish;
- confident, powerful, commercially readable presence;
- disciplined visual hierarchy and immediately readable silhouettes;
- controlled contrast between warm highlights and cooler or deeper structural values;
- restrained use of rich metallic gold or golden-orange as an accent, never as a substitute for structure;
- materially credible surfaces and lighting at the detail scale supported by the modality;
- exact, deliberate brand integration with no casual approximations, truncation, or motif clutter;
- one coherent rendering system across each component and convincing integration between components.

For the Legacy emblem, the actual canonical shape is primary and the black-and-gold color scheme is secondary. A scene-native embodiment may reinterpret material, perspective, light, architecture, atmosphere, or vegetation, but it must preserve recognizable canonical topology.

## Promoted design-language interpretation

Nate has explicitly promoted the following abstract qualities associated with `LEGACY_OFFICE_MASTER` for cross-modal use: dark-luxury discipline, black/charcoal structural grounding where the scene permits it, warm gold or golden-orange accents, warm/cool lighting contrast, polished commercial finish, and restrained brand readability.

This promotion does **not** transfer the office's furniture, room layout, equipment, props, photographic appearance, or incidental embedded marks into unrelated scenes. `LEGACY_OFFICE_MASTER` remains the sole authority for the Legacy workspace archetype and its assigned components. `LEGACY_LOGO_MASTER` remains the sole Legacy logo authority.

## Rendering-hybrid rule

Environment and character components may use different but compatible rendering profiles. The intended baseline hybrid is deliberately rendered 3D CGI environments with semi-realistic illustrated anthropomorphic characters when both components are present.

Cross-component coherence is established through shared perspective, light direction, shadow behavior, value hierarchy, edge treatment, and finish—not by forcing both components into the same technique.

## What is not universal

The following are profile-specific tools, not global requirements:

- photoreal PBR materials;
- bold black outlines or cel shading;
- volumetric lighting;
- pixel clusters, limited palettes, or hard aliasing;
- painterly brushwork and soft atmospheric edges;
- black/charcoal recoloring of every scene;
- gold signage, wordmarks, apparel marks, or repeated logo placements;
- muscular characters, wardrobes, props, or office furnishings when no controlling character or environment source is invoked.

Applying these indiscriminately is modality shock, not governance.

## Restraint and craftsmanship

- Do not add brand marks merely because a surface is available.
- Any literal mark must be a complete, precise embodiment of the authorized canonical artwork.
- Any scene-native embodiment must be complete, untruncated, materially coherent, and intentionally composed.
- A highly visible reimagining is permitted when explicitly authorized; novelty does not excuse crude topology or hasty execution.
- One excellent embodiment outranks several approximate repetitions.

## Pre-generation visual contract

Before generation, resolve and record:

1. exact source bytes and jurisdiction for every invoked source;
2. selected rendering modality profile for each major component;
3. properties held from the base input;
4. properties intentionally redesigned;
5. authorized motif form, surface, count, and placement envelope;
6. integration rules between modalities;
7. explicit exclusions, evaluation gates, and hard stop.

If the rendering profile or redesign envelope is unresolved, stop rather than infer it from the input.
