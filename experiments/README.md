# Experiments

This directory holds versioned, preregistered experiment packets and evaluation handoffs. Laboratory outputs and evaluation images remain in Google Drive.

## Current status

- `F0-S`: complete; baseline control distribution.
- `F0-V`: complete; partial support for within-master view arbitration.
- `F0-P`: planned but not frozen. Do not write or run its final A/B prompts until Release Candidate 1 and exact held constants are confirmed.

Each frozen experiment must contain purpose, hypothesis, exact condition prompts, held constants, exclusions, cycle plan, preregistered rubric, blinded evaluation handoff, and decision rules.
